# Теплицы39

Лендинг магазина теплиц завода «Воля» в Калининграде — [teplica39.ru](https://teplica39.ru).

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | весь сайт: разметка, стили и скрипты в одном файле |
| `privacy.html` | политика обработки персональных данных, cookie, условия использования |
| `admin/index.php` | панель управления фотографиями, вход по паролю |
| `content/photos.json` | какие фото показывать; правится из панели |
| `img/` | фотографии |
| `robots.txt`, `sitemap.xml` | для поисковых систем |

Статический сайт: базы данных и сборки нет, PHP нужен только для панели фотографий.

## Панель фотографий

`/admin` — при первом открытии предлагает задать пароль, дальше вход по нему.
Позволяет менять фото моделей и главное фото, наполнять галерею «Наши работы».
Принимает JPG, PNG и WEBP до 8 МБ; тип файла проверяется по содержимому,
имя генерируется автоматически.

## Требования

PHP 8.1+ для панели. Сама страница работает и без PHP.
